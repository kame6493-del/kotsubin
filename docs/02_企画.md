# 企画: こつびん

## 名前
- アプリ名: こつびん(こつこつ+びん。日本語の造語)
- ストアの題名: こつびん ハムスターと作業・勉強の記録
- 同名の確認(iTunes Search API、country=jp、2026-10-09): 「こつびん」「コツビン」は0件一致(出てきたのは別名の2本)。
  先に考えた「こつあみ」(編み物)は、別の作業者の歩数計のフォルダ名「てくあみ」と並ぶと同じ系列に見えるのでやめた。編み物という題材も歩数計側と被るおそれがあるので外した。「ホシツブ」は同名アプリがあるので不可。

## 一言の売り文句
がんばった時間が、びんの金平糖になる。

## どんなアプリか
「はじめる」を押すと、となりのハムスターが金平糖をみがき始める。10分ごとに1粒、作業の種類の色をした金平糖がびんに落ちる。
1日で1びん。月のカレンダーが、びんの並んだ棚になる。日のびんを押すと、その日の記録が出て直せる。

金平糖は、砂糖の蜜を少しずつかけて何日もかけて角を育てるお菓子。「こつこつ」がそのまま形になる。

## 勝ち組から押さえること
- ドット絵の相棒が主役、ほかは静かな画面(ねこ勤怠の「素朴なドット絵」「統一感」)。
- 相棒に名前を付けられる。
- ひと押しで始まる。アカウントなし・広告なし・記録は端末の中だけ。
- 状況で変わる短い一言(煽らない)。
- ひとやすみ中は相棒が眠り、決めた時間がたつと起きて知らせる。
- 日・週・月・累計の振り返り。

## 不満をつぶす(01 の表に対応)
- 過去の記録を何日前でも分単位で直せる・足せる・消せる。消したら「もとに戻す」が出る。
- 日付をまたぐ記録は日ごとに分けて数える。1日の区切りを0時〜5時で選べる(夜型・夜勤向け)。
- 時計は開始時刻から数えるので、裏に回しても画面を消してもアプリを落としても止まらない・ずれない。
- 12時間を超えてつけっぱなしなら、開いたときに「いつ終わった？」と聞いて直せる。
- 保存は1本ずつ順番に書き、前回の控えを残す。版が上がっても記録の形を読み替える。
- 言葉は「はじめる / ひとやすみ / つづける / おしまい」。出勤・退勤は使わない。
- 作業の種類は「しまう」だけで消さない。しまった物はいつでも戻せる。
- 棚のびんを押せばその日の中身。月・週・累計の合計も出す。
- 目標は曜日ごとに決められる(0分もあり)。
- 区切りやひとやすみの終わりは、通知+振動+画面の色の変化で知らせる。
- 軽く作る(絵はドット絵を手で決めた格子、音声・動画なし)。iPhone SE 幅で下のボタンが切れない。
- 無料の機能を後から有料にしない、とアプリ内の購入画面にも書く。サブスク・トライアルは無し。

## ひと目で分かる違い(1つ)
時間がびんの金平糖になって、月のカレンダーが「びんの棚」になる。
ほかは時間を数字かキャラの歩いた距離で見せる。こつびんは色つきの粒で見せるので、1日が何でできていたかが絵1枚で分かり、そのまま X に出せる。

## 無料でできること(機能は全部)
- 記録(はじめる・ひとやすみ・おしまい・種類の切り替え)、過去の記録の修正・追加・削除
- びん・棚・合計・累計、曜日ごとの目標
- 相棒「もち」(ハムスター)と名前付け
- 作業の種類の追加・色・並べ替え・しまう/戻す
- 区切りとひとやすみの通知、1日の区切り、ダークモード
- その日のびんを画像で保存・共有

## 課金で開くこと
「なかまセット」買い切り1回: 相棒が3匹増える(シマエナガ・うさぎ・ペンギン)+ びんの形が2つ増える(かくびん・つぼ)。見た目だけで、記録の機能は何も閉じない。

## 値段
¥500 の買い切り(非消耗型)。
理由: 勝ち組の不満で最も星1が集まったのはサブスクとトライアルの請求(FocusFlight・Synaps)。ねこ勤怠の月額¥300は「応援」の形で受け入れられている。こちらは一度払えば終わる形にして、見た目の追加だけを売る。

## 設定に書く値(src/config.ts)
- RevenueCat: キーは空(ios / android)。空なら「購入は準備中です」と出して落ちない。
- 商品ID: kotsubin_nakama_set / entitlement: nakama
- appId: jp.kotsubin.app

## 画面
1. はじめて(2画面まで、飛ばせる): 「がんばった時間が、びんの金平糖になる」→ 相棒の名前(そのままでも可)→ きょう。
2. きょう: 上に相棒とびん、真ん中に今日の合計と一言、下に種類の選択と大きな「はじめる」。動いている間は経過時間と「ひとやすみ」「おしまい」。
3. たな: 月のカレンダーがびんの棚。週・月・累計の合計、種類ごとの割合。
4. 日の記録: その日のびん、記録の一覧(押して直す)、記録を足す。
5. せってい: 相棒、名前、作業の種類、曜日ごとの目標、ひとやすみの長さ、区切りの通知、1日の区切り、見た目(自動/ライト/ダーク)、なかまセット、購入の復元、プライバシー。
