## 勝ち組の不満をつぶせたか

| 不満 | こつびん |
|---|---|
| 前の日・分単位で直せない | 何日前でも分単位で、足す・直す・消す・もとに戻す(E2E で確認) |
| 日付またぎ | 日ごとに分けて数える。1日の区切りを0〜5時で(time.test.ts) |
| 裏に回すと止まる・ずれる | 開始時刻から数える。E2E で時計を15分進めて確認、単体テストで3時間後も正しい |
| 記録が消える | 保存は順番に1本ずつ、前回の控えを残す。読めない所だけ直して読む(data.test.ts) |
| 無料の物を後から有料に | 購入画面に「あとから有料にすることはありません」 |
| 広告 | 無し |
| 重い | 絵はドット絵の格子(数KB)、音声・動画なし。APK 6.6MB |
| SE で下が切れる | 375x667 で確認 |
| 「出勤・退勤」 | はじめる/ひとやすみ/おしまい |
| 消したカテゴリを戻せない | 「しまう」と「戻す」 |
| 日を押して中身・累計・曜日ごとの目標 | たなの日付→その日の記録、これまで全部、曜日ごとの目標 |
| 終わりに気づけない | 通知+振動+画面の色が変わる+上に帯 |
